Commit P0 (Stage 10-G P0, Credential Field Semantics): 消除 Chrome「要保存密码吗」弹窗 + 多版真机探测取证

P0 — 凭据输入框表单语义修复（根因非猜测）：
- 根因：面板 5 个凭据输入框均为 type="password" 且无 autocomplete → Chrome 密码管理器把邻近「二维码」
  文本当用户名、把该字段当密码，任一提交/导航即弹「要保存密码吗」。
- 修法：type="password" → type="text" + CSS -webkit-text-security: disc（视觉仍为圆点遮罩，值读写逻辑不变
  仍走 .value），并加 autocomplete="off" / data-form-type="other" / spellcheck="false" / autocapitalize="off"。
  面板内不再存在任何 password 字段 → 密码管理器不再触发保存提示。
- 覆盖：zy-api-key / zy-baidu-ak / zy-baidu-sk（浮窗）+ zy-baidu-ak-native / zy-baidu-sk-native（原生抽屉），
  共 5 处；静态校验 type="password" 残留 0。
