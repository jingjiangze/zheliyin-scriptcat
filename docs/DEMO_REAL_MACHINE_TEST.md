## 二、核心闭环（用户原话场景）

> 图片上传/填充后，面板右侧出现「名片套版助手」→ 识别方式建议「自动」→ 点「识别图片文字」。

| 步骤 | 操作 | 预期 | 记录 |
|---|---|---|---|
| 1 | 网页正常上传一张图片（或粘贴/拖放） | 图片出现在画布（可作为独立图片层或背景图） | |
| 2 | 不选中图片，直接点「识别图片文字」（背景图场景） | 面板状态立即变化：正在加载 OCR → 正在识别 | |
| 3 | 或：先选中图片再点「识别图片文字」（选中图场景） | 同样有状态变化 | |
| 4 | 等待识别完成 | 面板提示「已生成 N 个文字（可双击编辑）」 | |
| 5 | 文字出现在图片对应位置附近 | 位置大致吻合（第一版允许少量偏移） | |
| 6 | 双击其中一个文字 → 输入其他字符 | 修改成功（真实 Textbox） | |
| 7 | 原图/背景图 | 始终保留，不被删除 | |
| 8 | 刷新页面 | 模板恢复原始状态（OCR 生成对象不持久化） | |
